# The Black Barn

Website for a fictional seasonal haunted house experience. Cinematic, scroll-driven, mobile-first.

## Repo

```
docs/creative-direction.md   Full creative direction package — source of truth
tokens/design-tokens.json    Color, type, motion, texture tokens
CLAUDE.md                    Build instructions for Claude Code
```

## Start here

1. Read `docs/creative-direction.md` end to end. §2 (visual system), §3 (motion), §4 (homepage architecture) and §5 (copy) are binding.
2. `CLAUDE.md` has the stack, build order, and the constraints that are easy to violate.
3. Build the hero (`§01 The Bus`) first and verify it on a real mid-tier Android over 4G. That is the go/no-go gate — if the hero doesn't hold up on a phone, nothing downstream matters.
